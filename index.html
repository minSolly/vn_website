Lerp::easeInOut, Lerp::bounce vn::Lerp 
f32 Lerp::easeInOut(f32 a, f32 b, f32 t) {
    return t < 0.5f
        ? a + (b - a) * (2 * t * t)
        : a + (b - a) * (1 - std::pow(-2 * t + 2, 2) / 2);
}

f32 Lerp::bounce(f32 a, f32 b, f32 t) {
    const f32 n1 = 7.5625f, d1 = 2.75f;
    if (t < 1 / d1) t = n1 * t * t;
    else if (t < 2 / d1) { t -= 1.5f / d1; t = n1 * t * t + 0.75f; }
    else if (t < 2.5f / d1) { t -= 2.25f / d1; t = n1 * t * t + 0.9375f; }
    else { t -= 2.625f / d1; t = n1 * t * t + 0.984375f; }
    return a + (b - a) * t;
}
void Timer::update(f32 dt) {
    if (paused) return;
    wasDone = finished;
    elapsed += dt;
    if (elapsed >= duration) {
        if (repeating) { elapsed -= duration; finished = true; }
        else finished = true;
    }
}

bool Timer::justFinished() {
    if (repeating) {
        bool r = finished && !wasDone;
        if (r) finished = false;
        return r;
    }
    return finished && !wasDone;
}
void SceneManager::update(Engine& e, f32 dt) {
    if (next && next != current) {
        if (current) current->onExit(e);
        current = next;
        next = nullptr;
        if (current) current->onEnter(e);
    }
    if (current) current->update(e, dt);
}
void Engine::drawImage(Image& img, f32 x, f32 y, f32 scale, f32 angle, Color tint) {
    if (!img.tex) return;
    SDL_Rect dst = { (int)x, (int)y, (int)(img.w * scale), (int)(img.h * scale) };
    SDL_SetTextureColorMod(img.tex, tint.r, tint.g, tint.b);
    SDL_SetTextureAlphaMod(img.tex, tint.a);
    SDL_RenderCopyEx(renderer, img.tex, nullptr, &dst, angle, nullptr, SDL_FLIP_NONE);
}
architecture

One loop, one manager, no surprises

Engine::run polls input, ticks the clock, and calls your two callbacks. Scenes sit on top as an optional layer with four lifecycle hooks.

built for sprites

Everything a 2D game actually needs

rendering

Logical resolution scaling

Design at one resolution; SDL scales and letterboxes the window for you.

motion

Six easing curves

Linear, easeIn, easeOut, easeInOut, smoothstep, and bounce, on floats and Vec2.

timing

Repeating, pausable timers

Query progress, remaining time, or a single justFinished() edge per cycle.

structure

Scene lifecycle hooks

onEnter, update, draw, onExit — swap scenes without tearing down the engine.

input

Just-pressed detection

Held and edge-triggered states for both keyboard and mouse, out of the box.

audio

32-channel mixer

Independent sound effects on top of looping music, with per-channel volume.

debugging

Toggleable debug grid

A 50/100px overlay with a live mouse crosshair, one call away.

rendering

Tinted, rotated draws

Color and alpha modulation plus rotation, on every sprite call.

get started

Three commands to a running window

  1. 1

    Clone it

    Pull the repository — no package manager, no account required.

  2. 2

    Configure with CMake

    Points at your local SDL2, SDL2_image, SDL2_mixer, and SDL2_ttf.

  3. 3

    Build and run

    Produces a single binary that opens straight into your update/draw loop.

$ git clone https://github.com/vnengine/vnengine.git $ cd vnengine && cmake -B build -DCMAKE_BUILD_TYPE=Release -- SDL2, SDL2_image, SDL2_mixer, SDL2_ttf found $ cmake --build build -- built ./build/vnengine_demo $ ./build/vnengine_demo
